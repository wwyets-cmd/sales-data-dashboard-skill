# 看板整体结构

## 顶部全局区

- 全局筛选：年度、月度、客户、客服、业务员、品牌下拉
- 全局开关：是否纳入调货客户统计

## 看板分区

1. 全局销售总看板
2. 业务 & 客服业绩看板
3. 公司总目标看板
4. 分析建议模块（产品 × 市场增长矩阵）

### 全局销售总看板

- 总销售额（万元）、总出库数量（万个）、客户数量（附带同比）
- **月度趋势 / 月度同比：全部年份连续展示，不受顶部年份选择器限制**
- 客户销售趋势、品牌销售占比
- 客户维度排名、客户明细下钻
- 成本计算，区分调货客户

### 业务 & 客服看板

- KPI 汇总卡片（金额万元 / 数量万个，个人任务额 + 同比）
- 多维度排名表（可切换排序字段）
- 多组月度趋势图（金额万元 / 数量万个 / 新客户 / 沉睡激活）
- 下钻：业务员 / 客服 → 客户清单 + 销售明细

### 公司总目标看板

- 公司级 KPI 卡片（目标 / 实际 / 完成率 + 同比；金额万元、数量万个）
- 月度目标进度趋势图
- 业务员 / 客服 / 品牌完成率排名
- 无明细下钻
