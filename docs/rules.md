# 业务口径总规则

1. **字段自动识别**：多系统导出文件，自动匹配别名：客户、业务员、客服、品牌、出库日期、金额、数量。
2. **沉睡客户**：以最新单据日期往前滚动 6 个月，累计采购 < 1000 元（金额阈值仍按元口径判定）。
3. **沉睡激活**：沉睡客户，后续单月出库金额 > 1000 元，判定激活（金额阈值仍按元口径判定）。
4. **新客户**：按首次出库日期判定。
5. **同比**：选中统计周期，对比上一年同期。
6. **调货客户**：独立开关，全局所有看板统一控制是否纳入统计。
7. **筛选联动**：全部子看板跟随顶部年度 / 月度 / 维度筛选器联动刷新。
8. **公司目标数据**：由用户单独提供，不来源于出库单据。
9. **总览月度同比（连续年显示）**：全局销售看板的月度趋势 / 月度同比图，必须按数据源内**全部年份连续展示**（横轴为 1–12 月、每个年份一条折线，或按连续年月排列），**不受顶部年份选择器控制**，以便跨年同月对比；客户 / 客服 / 业务员 / 品牌等维度筛选器与调货开关对该图仍然生效。
10. **计量单位**：全看板金额统一以 **万元** 为单位（原始金额为元，除以 10000，默认保留 2 位小数）；数量统一以 **万个** 为单位（原始数量为个，除以 10000，默认保留 2 位小数）。沉睡 / 激活等金额阈值（1000 元）仍以元为判定口径，不受展示单位影响。
