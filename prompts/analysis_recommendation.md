# 分析建议子模块（产品 × 市场 增长矩阵）

> 对外统一名称为 **「分析建议」**，不在看板 / 报告中出现"安索夫"字样。
> 内部沿用「产品（现有 / 新）× 市场（现有 / 新）」的 2×2 增长矩阵逻辑。

## 一、必须直接输出模型图

收到分析建议相关指令时，**直接渲染一张 2×2 矩阵模型图**（不要只给文字）：

- 纵轴：产品（上 = 现有产品，下 = 新产品）
- 横轴：市场（左 = 现有市场，右 = 新市场）
- 四个象限各为一张卡片，卡片内**同时展开该象限对应的「客户」与「产品」清单**，
  以及一句话动作建议。
- 矩阵图跟随客户 / 客服 / 业务员 / 品牌等维度筛选器与调货开关联动。

布局示意：

```
                现有市场                          新市场
现有产品   ┌─────────────────────┐      ┌─────────────────────┐
           │ ① 市场渗透          │      │ ② 市场开发          │
           │ 客户：…（展开清单） │      │ 客户：…（展开清单） │
           │ 产品：…（展开清单） │      │ 产品：…（展开清单） │
           └─────────────────────┘      └─────────────────────┘
新产品     ┌─────────────────────┐      ┌─────────────────────┐
           │ ③ 产品开发          │      │ ④ 多元化（谨慎）    │
           │ 客户：…（展开清单） │      │ 客户：…（展开清单） │
           │ 产品：…（展开清单） │      │ 产品：…（展开清单） │
           └─────────────────────┘      └─────────────────────┘
```

## 二、各象限客户与产品的归类口径

清单基于当前数据动态生成；数据中尚不存在的（新市场 / 规划新品）标注
"待开拓 / 待规划"，并提示用户补充，不得编造具体名称。

### ① 市场渗透｜现有产品 × 现有市场（低风险，短期核心）
- **客户（展开）**：现有活跃客户、高价值复购客户；沉睡客户单列并标注"待激活"。
- **产品（展开）**：当前在售、有出库记录的主力产品 / 常销规格。
- 动作：提升复购与客单、交叉销售、沉睡客户激活。

### ② 市场开发｜现有产品 × 新市场（中风险，并行推进）
- **客户（展开）**：本期新增客户（按首次出库日期）、新区域 / 新行业潜在客户。
- **产品（展开）**：可直接复制到新市场的成熟现有产品。
- 动作：把成熟产品卖向新区域 / 新客户群体。

### ③ 产品开发｜新产品 × 现有市场（中风险，存量稳定后启动）
- **客户（展开）**：适合承接新品 / 配套品的现有高价值客户。
- **产品（展开）**：近期首次出现的新品、配套件 / 升级款；规划中标注"待规划"。
- 动作：依托现有客户信任推新品、配套组合销售。

### ④ 多元化｜新产品 × 新市场（高风险，谨慎）
- **客户（展开）**：全新目标客户群体（现有数据没有则标注"待开拓"）。
- **产品（展开）**：全新品类产品（标注"待规划"）。
- 动作：充分评估投入产出与风险，现阶段不作为重点。

## 三、输出格式

1. **2×2 模型图**（四象限卡片，各含客户清单 + 产品清单 + 动作建议）。
2. 每个清单标注来源：已存在（来自数据）/ 待开拓 / 待规划。
3. 象限优先级排序与理由（默认 ① → ② → ③ → ④，可按数据调整）。
4. 关联看板监控指标（沉睡激活、新增客户、新品采购、目标完成率等）。
