# sales-data-dashboard-skill

> B端销售客户数据分析看板 + 分析建议自定义 Skill
> 适用：建材 / 五金类 B 端销售。自动解析多系统导出的客户出库单据，生成可视化业务看板、业绩排名、目标达成分析，并配套产品 × 市场增长矩阵给出分析建议。

## ✨ 能力清单

1. **全局数据看板**：多维度筛选、字段自动别名识别
2. **客户销售分析**：客户分层、沉睡客户判定、客户下钻明细
3. **业务 & 客服业绩看板**：多维度 KPI、排名、趋势图、沉睡激活统计、个人任务额对比
4. **公司总目标看板**：目标 vs 实际、完成率、月度进度趋势、多维度完成率排名
5. **分析建议（产品 × 市场增长矩阵）**：四象限诊断，输出业务落地建议

## 📌 核心业务口径

- **沉睡客户**：以最新单据日期往前滚动 6 个月，累计拿货金额 < 1000 元
- **沉睡激活**：原为沉睡客户，后续单月出库金额 > 1000 元，判定为激活
- **新客户**：按首次出库日期判定
- **同比规则**：选中周期对比上一年同期
- **调货客户**：独立开关，可选择是否纳入全部统计、业绩与目标完成率
- **字段兼容**：自动识别不同导出系统的表头别名（客户、业务员、客服、品牌等）

## 🧩 筛选联动规则

顶部全局筛选器（年度 / 月度 / 客户 / 客服 / 业务员 / 品牌）对所有子看板统一联动；调货客户开关全局统一生效。

## 📥 使用方法

1. 上传多系统导出的出库账单文件（.xls / .xlsx）
2. 单独发送公司年度 / 月度目标数据（目标金额、目标数量、目标客户数）
3. 指令支持：生成看板、查看排名、下钻明细、公司目标分析、分析建议
